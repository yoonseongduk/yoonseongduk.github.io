# 콘텐츠 등급 설문 · 데이터 보안 · 대상 연령 — 답변 가이드

> 설문은 **사실대로** 답해야 해요(거짓 응답은 앱 삭제 사유예요). 아래는 이 앱의 실제 기능을 기준으로 한 권장 답변이고, 최종 등급은 심사 결과로 정해져요. 등록 화면의 질문 문구는 바뀔 수 있어요.

## 1. 앱 액세스·광고·결제
| 질문 | 답 |
|---|---|
| 앱 전체를 로그인 없이 쓸 수 있나요? | 예(특별한 계정 필요 없음) |
| 광고가 있나요? | 아니요 |
| 앱 내 결제(유료 아이템)가 있나요? | 아니요 |
| 유료 앱인가요? | 아니요(무료) |

## 2. 콘텐츠 등급(IARC) 설문 — 권장 답변
> 앱을 1개로 등록하면 "도박" 행은 **모의 도박: 예**예요. 나중에 앱을 2개로 나누면(README 6번) 비성인용 앱은 "아니요"(그 게임이 앱에서 접근 불가일 때만), 카드·화투 앱은 "예"로 답해요.
| 항목 | 답 | 이유 |
|---|---|---|
| 폭력 | 없음 | 슈팅·잡기 게임은 있으나 만화적·추상적 표현(벌레 잡기, 우주 슈터 등) → 설문의 '판타지/만화 폭력' 질문이 있으면 "예(경미)"로 답하세요 |
| 성적 콘텐츠·노출 | 없음 | |
| 욕설·비속어 | 없음 | |
| 약물·담배·술 | 없음 | 약 복용 체크표는 건강 도구예요(오락 목적의 약물 아님) |
| 도박 | **모의 도박(시뮬레이션): 예** | 블랙잭(포인트 판돈)·맞고·고스톱·포커·행운 번호 뽑기가 있음. 실제 돈은 없음 |
| 사용자 간 상호작용 | 예 | 같이 하기(같은 와이파이에서 가족·친구와 게임 상태 주고받음). 자유 채팅 없음 |
| 위치 공유 | 아니요 | |
| 개인정보 공유 | 아니요 | 이름 명단은 기기 안에만 저장돼요(같이 하기에서 이름은 게임 화면에 보임) |
| 디지털 구매 | 아니요 | |

⚠ **모의 도박을 "예"로 답하면 등급이 높아질 수 있어요**(예: 12세·청소년 이용불가 수준). 한국에서는 사행성 표현이 있으면 청소년 이용불가가 될 수 있다고 알려져 있어요(정확한 기준은 등록 화면과 심사 결과로 확인 필요).
→ **결정이 필요해요**: 가족(어린이)용 앱 이미지를 유지하려면 스토어용 앱에서는 블랙잭(판돈)·맞고·고스톱·포커·훌라·행운 번호 뽑기를 빼는 방법이 있어요. 방법은 `README_플레이스토어_준비.md` 6번에 있어요.

## 3. 대상 연령(Target audience)
- 권장: **만 13세 이상**(성인·청소년 대상). 어린이(만 12세 이하)를 포함하면 '가족용(Designed for Families)' 정책의 엄격한 조건이 붙어요(카메라 권한·외부 링크·광고 SDK 등 검토 대상). 어린이도 쓸 수 있는 앱이지만, 스토어 표기 대상은 13세 이상으로 시작하는 것이 안전해요.
- 앱 안에서 어린이를 특정해 광고·추적을 하지 않아요.

## 4. 데이터 보안(Data safety) 양식
| 질문 | 답 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | **수집 안 함 / 공유 안 함** |
| 이유 | 모든 기록은 기기 안(브라우저 저장소)에만 저장되고, 개발자 서버가 없어요. 광고·분석 SDK 없음 |
| 선택 기능: 🌐 온라인 그림(명화 퀴즈·모음, 기본 꺼짐, 켤 때 동의 확인) | 켜면 위키백과·위키미디어 서버(제3자)에서 그림을 불러와 **기기의 IP 주소가 전달**돼요. 앱이 보내는 개인정보는 없어요. **스토어 제출 시 결정 필요(`playstore/스토어_관련_기록.md`)**: (A) `online.js`의 `ENABLED=false`로 끈 판을 올려 위 답변 그대로 "수집 안 함" 유지 (B) 켠 판을 올리고 Data safety에서 '기기 또는 기타 ID(IP 주소)'를 제3자로 전송하는 것으로 답변하고 방침(privacy.html)의 선택 기능 문구를 유지 |
| 데이터 전송 시 암호화 | 해당 없음(기본 상태는 전송 없음). 온라인 그림은 https |
| 데이터 삭제 요청 | 앱 데이터 삭제(기기 설정) 또는 앱 삭제로 모두 지워져요. 방침 페이지에 안내됨 |
| 카메라 권한 | QR 코드 읽기에만 사용, 저장·전송 없음(기기 안에서 처리) |
| 알림 권한 | 약 복용 알림(선택, 기기 안에서만) |
| 개인정보 처리방침 URL | https://yoonseongduk.github.io/privacy.html |

## 5. 건강 앱 선언(해당 시)
약 복용 체크표·혈압·혈당 기록장·BMI 계산기가 있어서 "건강 관련 기능" 질문이 나오면: 의학적 진단·치료 앱이 아니고, 입력 내용은 기기에만 저장되며, 참고용(진단 대신 아님)이라고 답하세요. 앱 안에 "진단이 아니에요·의사와 상담" 문구가 이미 있어요.

## 6. 정책 관련 메모
- AI 생성 그림(화투 새 민화, 트럼프 카드, 윷 결과 카드)을 썼어요. 스토어에 "AI 생성 콘텐츠" 질문이 있으면 사실대로 답하세요. 앱 안 '출처와 저작권'에 밝혀 두었어요.
- 화투 그림(옛 화투)은 CC BY-SA 4.0 그림이에요. 저작자 표기는 앱 안에 있어요.
- 한자·낱말 데이터 출처 일부는 사용 조건이 불명확해요 → `게임_변경이력.md`·점검 보고 참고(등록 전 확인 권장).
