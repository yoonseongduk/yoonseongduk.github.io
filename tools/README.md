# 가족 미니 게임 관리 방법

## 폴더 구성
- `index.html` : 시작 화면 (게임 목록은 이 파일의 `GAMES` 목록에 한 줄씩 적혀 있어요)
- `*.html` : 게임 하나가 파일 하나예요
- `sw.js` : 폰에 게임을 저장해서 오프라인으로 하게 해 주는 파일 (**직접 고치지 마세요**, 아래 도구로 자동 생성)
- `manifest.webmanifest`, `icon-*.png` : 폰에 앱으로 설치할 때 쓰는 이름과 아이콘
- `fonts/` : 오프라인에서도 같은 글씨가 나오게 사이트에 넣어 둔 글꼴
- `tools/` : 관리 도구

## PC에서 고친 뒤 사이트에 올리는 방법
1. 파일을 고치거나 새 게임 파일을 폴더에 넣어요. (새 게임은 `index.html`의 `GAMES` 목록에도 한 줄 추가해야 시작 화면에 나와요.)
2. `tools\올리기.bat`을 더블클릭해요.
3. 질문이 나오면 변경 내용을 짧게 적고 엔터를 눌러요.
4. "완료!"가 보이면 끝이에요. 1~2분 뒤 사이트에 반영돼요.

이 파일이 하는 일: 최신 내용 받기(`git pull`) → `sw.js` 새로 만들기 → 저장(커밋) → 올리기(`git push`).

### 준비물
- Git for Windows (이미 설치하셨어요)
- Python 3 (https://www.python.org). `py --version`을 입력했을 때 `Python 3.xx.x`가 나오면 준비된 거예요. (`python`만 입력했을 때 이름만 나오면 가짜 연결이니 `py`를 쓰세요.)
- 처음 올릴 때 GitHub 로그인 창이 뜰 수 있어요.

## `sw.js`만 다시 만들고 싶을 때
```
py tools\make-sw.py
```
게임 파일을 고치거나 추가했다면 올리기 전에 꼭 한 번 실행하세요. (`올리기.bat`이 대신 해 줘요.)

## 폰에 새 버전이 들어가는 방법
인터넷이 되는 상태에서 폰의 앱을 열면 새 버전을 뒤에서 받아요. 앱을 닫았다가 다시 열면 새 내용이 보여요. 인터넷이 안 되면 예전 버전이 그대로 돌아가요.

## 주의
- `올리기.bat`은 폴더 안의 **모든 변경**을 올려요(`git add -A`). 올리면 안 되는 파일(메모, 임시 파일 등)은 이 폴더에 두지 마세요.
- 이 저장소는 공개예요. 비밀번호 등을 파일에 적어 두지 마세요.
- Claude가 사이트를 고쳐 올린 뒤에는 PC에서 `git pull`을 먼저 하세요. (`올리기.bat`은 자동으로 해 줘요.)
