## 지금의 위험 평가 (법률 자문 아님)
| 자료 | 우리가 쓰는 것 | 판단 |
|---|---|---|
| 한자 급수(한국어문회) | 한자 3,500자의 급수·훈음·부수·획수 | "어느 한자가 몇 급인가"는 사실 정보라 위험이 낮은 편이지만, 한국어문회가 자료 전체를 편집저작물로 주장할 수는 있어요. 허락을 받으면 가장 안전해요. 출처 표기는 이미 했어요. |

## 1. 한국어문회에 보내는 글
**받는 곳**: 사단법인 한국어문회 (https://www.hanja.re.kr — 누리집의 문의 창구 이용)
**제목**: 한자능력검정시험 급수 자료 사용 허락 문의

안녕하세요. 가족과 즐기려고 한자 학습 게임(퀴즈·쓰기 연습)을 만든 개인 개발자 ○○○입니다.

앱 안에서 한자능력검정시험 급수별 한자 목록(한자, 훈·음, 급수, 부수, 획수)을 사용하고 있고, 이 자료는 귀 회 누리집에 공개된 학습자료를 CSV로 변환해 올린 GitHub 자료(rycont/hanja-grade-dataset)를 바탕으로 합니다. 앱은 무료이고 광고·결제가 없으며, 이용자의 정보를 수집하지 않습니다. 앱 안에 "자료의 저작권은 한국어문회에 있고, 이 앱은 한국어문회와 관련이 없으며 공식 시험 자료가 아니다"라고 밝혀 두었습니다.
앞으로 구글 플레이 스토어에도 무료로 올릴 계획이라 사용 조건을 정확히 확인하고 싶습니다.

2. 허락해 주신다면 앱 안에 넣어야 하는 출처 표기 문구가 있는지요?
3. 사용이 어렵다면 어떤 범위까지 가능한지(예: 급수 구분만 사용) 알려 주시면 따르겠습니다.

**제목**: 표준국어대사전 표제어(낱말 목록) 이용 조건 문의

## 5. 끝말잇기를 우리말샘으로 바로 교체하는 방법 (문의 없이도 가능)
1. 본인 PC에서 우리말샘(https://opendict.korean.go.kr) → 회원가입·로그인 → **사전 내려받기**에서 전체 JSON(또는 XML) 파일을 받아 한 폴더에 풀기(한국어기초사전 https://krdict.korean.go.kr 파일도 가능, 이 환경에서는 접속이 막혀 직접 받지 못했어요).
2. 확인: `py tools\dev\build_words_from_opendict.py 폴더경로` → 새 목록 낱말 수와 현재 목록과의 겹침 비율이 나와요(현재 목록의 약 70% 이상을 담으면 쓸 만해요).
3. 적용: `py tools\dev\build_words_from_opendict.py 폴더경로 --apply` → `data/words-ko.txt`가 바뀌고 `data/words-ko-LICENSE.txt`(CC BY-SA 2.0 KR)가 생겨요. 이어서 `licenses.html`의 끝말잇기 항목에 "국립국어원 우리말샘(CC BY-SA 2.0 KR) 기반"을 적고 `py tools\make-sw.py` 후 올려요.
4. 도구는 샘플 데이터로만 시험했어요. 실제 파일에서 낱말이 너무 적게 나오면 알려 주세요(파일 모양에 맞게 고쳐요).
> 참고: 라이선스가 분명한 다른 후보였던 hunspell 한국어 사전(`ko.dic`, 국립국어원 데이터는 CC BY-SA)은 활용형 위주라 우리 목록과 겹치는 낱말이 3만 개뿐이라 대체재로 쓸 수 없었어요.
