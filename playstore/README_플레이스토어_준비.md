# 구글 플레이 스토어 등록 준비 가이드 (초보자용)

이 앱은 웹사이트(PWA)라서, **TWA(신뢰할 수 있는 웹 활동)** 방식으로 안드로이드 앱 파일(.aab)을 만들어 올려요. 앱 안의 내용은 지금 사이트 그대로 보여요(그래서 게임을 고치면 앱도 자동으로 새로워져요).

## 1. 본인이 해야 하는 일 (제가 대신할 수 없는 것)
1. **구글 플레이 개발자 계정 만들기** — https://play.google.com/console (등록비 약 US$25, 1회). 개인 계정은 본인 확인(신분증·주소·전화)이 필요해요.
2. **(개인 신규 계정) 비공개 테스트 요건** — 개인 계정은 정식 출시 전에 일정 수 이상의 테스터가 일정 기간(예: 12명·14일) 비공개 테스트를 해야 하는 규정이 있었어요. **지금도 그대로인지 등록 화면에서 확인하세요(확인 필요)**. 가족·친구에게 부탁해 테스터로 등록하면 돼요.
3. **앱 서명 키 보관** — 아래 2번에서 만드는 키 파일(`.keystore`)과 비밀번호는 **절대 잃어버리면 안 돼요**(잃으면 업데이트가 어려워져요). 이 저장소(공개)에는 올리지 마세요. 플레이 콘솔의 "Play 앱 서명"을 켜면 위험이 줄어요.

## 2. 앱 파일(.aab) 만들기 — 방법 A (추천, 가장 쉬움: PWABuilder)
1. 브라우저에서 https://www.pwabuilder.com 접속 → 주소에 `https://yoonseongduk.github.io` 입력 → 점검 결과를 확인(문제가 있으면 알려 주세요).
2. **Package for stores → Android** 선택.
3. 패키지 이름(예: `io.github.yoonseongduk.familygames`) 입력, 시작 주소는 `https://yoonseongduk.github.io/index.html` — **한 번 정하면 평생 못 바꿔요.** 앱 이름 "우리 가족 미니 게임", 짧은 이름 "가족 게임", 버전 1.0.0(코드 1).
4. 서명 키: "새로 만들기" 선택 → 다운로드된 압축 파일에 `.aab`, **서명 키(.keystore) + 비밀번호 파일**, 그리고 **`assetlinks.json`** 내용이 들어 있어요.
5. 키 파일과 비밀번호를 안전한 곳(본인 PC 외장 디스크 등)에 백업하세요.

## 3. 방법 B (고급: Bubblewrap 명령줄)
- 컴퓨터에 Node.js·Java가 필요해요. `playstore/twa-manifest.template.json`이 견본이에요. 초보자는 방법 A를 쓰세요.

## 4. assetlinks.json 올리기 (주소 창 없이 앱처럼 보이게 하는 인증)
1. PWABuilder(또는 플레이 콘솔의 "앱 서명" 화면)에서 **SHA-256 인증서 지문**을 확인해요. 플레이 앱 서명을 쓰면 **플레이 콘솔이 보여 주는 지문**을 써야 해요(업로드 키와 다름).
2. `playstore/assetlinks.template.json`을 복사해서 패키지 이름과 지문을 채운 뒤, 저장소 맨 위에 `.well-known/assetlinks.json` 파일로 올려 주세요(저에게 지문을 알려 주시면 제가 만들어 올릴게요).
3. 확인: 브라우저에서 https://yoonseongduk.github.io/.well-known/assetlinks.json 이 열려야 해요.

## 5. 플레이 콘솔에서 등록하기
1. **앱 만들기** → 앱 이름·언어(한국어)·앱/게임·무료.
2. **스토어 등록정보**: `스토어_등록정보_초안.md`의 글을 붙여넣고, 아이콘·대표 이미지·화면 캡처(`screenshots/`)를 올려요.
3. **앱 콘텐츠**: 개인정보 처리방침 URL, 광고 없음, 앱 액세스, **콘텐츠 등급 설문**, 대상 연령, **데이터 보안** — `콘텐츠등급_데이터보안_답변.md`를 보고 사실대로 답해요.
4. **테스트 → 비공개 테스트**: `.aab` 업로드 → 테스터(가족·친구 이메일 목록) 등록 → 테스트 링크를 보내요.
5. 요건을 채운 뒤 **프로덕션 출시 신청** → 검토(보통 며칠) → 공개.

## 6. 모의 도박풍 게임 — 지금은 하나의 앱, 등록할 때 분리 가능
- **지금(결정)**: 블랙잭·맞고·고스톱·포커·하이로우·행운 번호 뽑기(같이 하기의 훌라·포커·블랙잭·맞고 포함)는 시작 화면의 **"🃏 카드·화투 놀이"** 분류로 따로 묶여 있고, "카드·화투 놀이 보기" 체크로 폰마다 켜고 끌 수 있어요. 앱은 **하나**로 관리해요.
- **플레이스토어에 등록할 때** 선택지:
  1. 그대로 한 앱으로 등록(설문에 "모의 도박: 예"로 정직하게 답하고 나온 등급을 받아들임)
  2. **같은 사이트로 앱 2개 등록**: 시작 주소를 `?app=store`(카드·화투 놀이 숨김, 비성인용)와 `?app=cards`(카드·화투 놀이만, 성인용)로 나눔. 이때 `casino.js`에 이 두 모드(주소 표시를 읽어 숨김/보임, 숨긴 게임을 직접 열면 시작 화면으로 돌려보내기)를 추가하면 돼요. 주의: 비성인용 앱에 모의 도박이 실제로 들어 있으면서 "없음"으로 답하면 안 되고(허위 응답), 내용이 같은 앱 2개는 스팸으로 거절될 수 있어서 성인용 앱은 카드·화투 놀이만 모은 앱으로 만드는 게 안전해요. 앱마다 패키지 이름·서명 키·assetlinks 항목이 따로 필요해요.
  3. 카드·화투 놀이 삭제
- 위 2번의 앱 ② 설명 글 초안은 `스토어_등록정보_초안.md` 아래쪽에 있어요(등록 시점에 쓸 초안).

## 8. 업데이트는 어떻게 되나요?
앱은 웹사이트를 보여 주므로, 게임을 고쳐 올리면(지금처럼) 사용자는 앱을 완전히 닫았다 열면 새 버전을 봐요. 앱 파일(.aab)을 다시 올릴 일은 앱 이름·아이콘·권한이 바뀔 때뿐이에요.
